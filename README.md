# CivicFix

CivicFix (formerly SpotFix) is an AI-powered hyperlocal issue reporting platform that enables citizens to identify, verify, track, and resolve community infrastructure problems with transparency and accountability.

## Features

- **AI-Powered Categorization:** Automatically categorizes reported issues and assesses severity using Gemini Pro Vision.
- **Automated Verification & Deduplication:** The AI Agent cross-references new reports with existing ones to deduplicate and verify infrastructure problems automatically.
- **Interactive Map:** Track issues in your neighborhood in real-time.
- **Civic Score:** Gamified leaderboards to encourage community engagement.

## Getting Started

1. Clone the repository.
2. Run `npm install`
3. Configure your Firebase and Google Maps API keys in `.env`
4. Run `npm run dev`
